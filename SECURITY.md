# Security policy

Do not open a public issue for a vulnerability that could expose credentials,
private events, personal data, payment information, or privileged database
operations.

Report security concerns privately to `christophe@conbinience.com` with the
affected component, reproduction steps, impact, and any suggested mitigation.
Do not include live secrets or unnecessary personal data. You should receive an
acknowledgement within seven days.

Ordinary dead feeds, parsing failures, duplicate events, and category mistakes
belong in public issues and are not security vulnerabilities.
